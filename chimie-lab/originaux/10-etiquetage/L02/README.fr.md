# L02 — Étiquette de col Ø32

*[English](README.md) · Français*

![Aperçu du STL](preview.jpg)

Ajouter une étiquette de rangement autour du col d'un flacon ; garder les mentions réglementaires et l'étiquette du fabricant visibles.

- Encombrement STL : **81.991 × 39.999 × 3 mm**.
- Matière candidate : **PETG**.
- Interface : Anneau fermé Ø intérieur 32 mm ; passer le col avant de refermer le bouchon, sans interférer avec sa fermeture.
- Fichiers : [L02.stl](L02.stl), [L02.step](L02.step), [L02.FCStd](L02.FCStd).
