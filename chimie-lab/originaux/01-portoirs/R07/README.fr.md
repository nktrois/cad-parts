# R07 — Portoir 12 flacons Ø20

*[English](README.md) · Français*

![Aperçu du STL](preview.jpg)

Organiser 12 flacons secs de petit diamètre.

- Encombrement STL : **118.8 × 90.8 × 27 mm**.
- Matière candidate : **PETG**.
- Interface : Puits Ø 20.8 mm ; mesurer le diamètre extérieur du récipient.
