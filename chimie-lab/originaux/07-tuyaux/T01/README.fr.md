# T01 — Organiseur 6 tuyaux Ø6.6

*[English](README.md) · Français*

![Aperçu du STL](preview.jpg)

Guider six tuyaux par leur extérieur, sans les pincer ni obturer leur lumière.

- Encombrement STL : **90.6 × 40 × 14 mm**.
- Matière candidate : **PETG**.
- Interface : Encoches ouvertes de 6.6 mm ; aucun contact direct avec le fluide.
- Fichiers : [T01.stl](T01.stl), [T01.step](T01.step), [T01.FCStd](T01.FCStd).
